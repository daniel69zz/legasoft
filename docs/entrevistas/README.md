# Entrevistas

Minutas, actas y transcripciones del relevamiento de requerimientos realizado
con los stakeholders de la organización cliente.

Cada sesión se identifica con un código:

| Prefijo | Uso |
| --- | --- |
| `ENT-NNN` | Entrevista de relevamiento o de validación |
| `VAL-NNN` | Sesión de validación complementaria |

Las necesidades que surgen de cada sesión se registran en el catálogo
`NEC-NN`, que es el origen de los requisitos de `docs/srs/`.
