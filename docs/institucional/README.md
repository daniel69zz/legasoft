# Documentación institucional

Documentos que definen la identidad y el marco organizativo de Legasoft.

| Archivo | Código | Estado |
| --- | --- | --- |
| `constitucion-legasoft.tex` | `LGS-INST-001` | Aprobado |
| `constitucion-cuerpo.tex` | — | Fragmento: cuerpo de la constitución (se incluye en la entrega) |
| `anexo-acta-constitucion.tex` | `LGS-INST-002` | Aprobado — acta de constitución de la consultora |
| `anexo-infraestructura.tex` | `LGS-INST-004` | Aprobado — repositorio, carpetas y gestión de configuración |
| `acta-constitucion-proyecto.tex` | `LGS-PRY-001` | Plantilla — acta de un proyecto con cliente |

**`constitucion-legasoft.tex`** es el documento fundacional: identidad
corporativa, líneas de servicio, misión, visión, valores, objetivos, normas
adoptadas como referencia, organigrama y definición de los tres roles.

**`acta-constitucion-proyecto.tex`** autoriza formalmente el inicio de un proyecto
concreto con un cliente: alcance,
entregables, hitos, interesados, supuestos, restricciones y riesgos.

Compilar con `make institucional` desde la raíz del repositorio.
